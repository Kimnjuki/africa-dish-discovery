# LadhaQuest

Authentic African & world recipes with smart pantry matching.

**Live site:** [https://www.ladhaquest.com](https://www.ladhaquest.com)

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase

## Local development

```sh
npm i
npm run dev
```

Build for production:

```sh
npm run build
```

## Deploy

This app is deployed via Coolify from `origin/main`. Push to `main` to trigger a redeploy.
